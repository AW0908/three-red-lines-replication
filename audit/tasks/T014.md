## Goal

The instructor (Windows, R ≥ 4.4) can run `run_all.R` from `replication.Rproj` without errors, and the guards still catch real content changes. Today the byte-identity guards in `01_clean.R` and `03_figures.R` would very likely abort on Windows: `data.table::fwrite` and `write.csv` write `\r\n` line endings on Windows by default, so freshly built files differ byte-wise from the shipped (`\n`) targets and from the hard-coded T004 panel hash.

## Steps

1. Make every text output platform-independent: pass `eol = "\n"` (or equivalent: `fwrite(..., eol = "\n")`, `writeLines` on a binary connection / `useBytes`, `write.csv` via a connection opened with `"wb"`) in all six pipeline scripts, so that macOS and Windows produce identical bytes. List every write call you changed in the report.
2. Make the guards robust: compare files after normalising line endings (strip `\r`) before hashing, in a small helper used by `01_clean.R` and `03_figures.R`; the hard-coded T004 hash stays the reference and must still match on macOS. Keep the abort for real content differences. Add an optional escape hatch: if environment variable `MTPA_GUARDS=warn` is set, mismatches produce a warning instead of an error; default stays strict. Document this in README.
3. `00_setup.R`: install/check only the packages in the `used` list; keep `did`, `rdrobust` in `environment.lock` but mark them in README as not needed for the build. Version mismatches only warn (as now).
4. `run_all.R`: make sure the call to Rscript works on Windows (use `file.path(R.home("bin"), "Rscript")` with `.exe` handled by R, quote paths with spaces, e.g. a project under `C:\Users\Prof Name\...`). Add a check that the working directory is `replication/` with a clear error message.
5. README:
   - New subsection "Operating systems": tested on macOS 26 with R 4.6.0; Windows not tested by the authors; on Windows open `replication.Rproj` in RStudio and run `source("run_all.R")` (or `Rscript run_all.R`); `run_all.sh` requires Git Bash/WSL; paths are relative; mention `MTPA_GUARDS=warn` as fallback.
   - Section 5: remove the contradiction on the Wind licence (old text "not permitted"/"cannot be included"). Correct statement: Wind exports are included solely so that the course instructor can replicate the results; no redistribution beyond the course.
   - Section 14 changelog: one consistent table, no duplicate T010 entry; add T014.
6. Simulate Windows line endings on macOS as a test: in a fresh copy, set a test hook (e.g. env var `MTPA_TEST_CRLF=1`, test-only, documented in report but not README) that writes outputs with `\r\n`, run the build, and show the guards pass; then run normally and show all outputs byte-identical to the project. Also run one negative test (change a value in a protected output) → guard aborts. Remove nothing else.
