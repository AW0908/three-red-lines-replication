## Estimator

Doubly robust DiD for panel data (Sant'Anna and Zhao 2020, improved locally efficient estimator): ATT = effect on treated firms of the pre-to-post change in outcome Y, combining a logit propensity score (inverse-probability weighting / covariate balancing) with a linear outcome regression for the comparison group's change. Use `DRDID::drdid_imp_panel` if the R package `DRDID` is installed; otherwise implement the estimator from the paper's formulas and validate it against a simulated example with known ATT. Inference: firm bootstrap (999 draws, fixed seed). Trim propensity scores outside [0.01, 0.99] and report the number trimmed. Report covariate balance (standardized mean differences) before and after weighting and a propensity-score overlap figure.

**Periods:** pre = 2019-12-31, post = 2021-12-31 (main); sensitivity: averages over 2017H1–2019H2 vs. 2020H2–2022H2. **Pre-trend check:** the same estimator for each pre-policy date vs. 2019-12-31 (placebo "effects" 2016H2–2019H1), shown as an event-study figure.

**Outcomes (same for all comparisons):** (Y1) 1{RL1 ∈ [0.66, 0.70)} – presence just below the threshold, the firm-level analogue of excess mass; (Y2) 1{RL1 ≤ 0.70} – compliance; (Y3) RL1 level; placebo outcome (Y4) 1{RL1 ∈ [0.56, 0.60)}.
