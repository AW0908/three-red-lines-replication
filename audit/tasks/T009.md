## Goal

The first estimates for "Preliminary Analysis": the effect of pre-policy treatment intensity (`dose`, number of red
lines breached at 2019-12-31) on reported leverage and on the indicators of cosmetic deleveraging, as a pooled
difference-in-differences and as an event study with a joint pre-trend test. Script `replication/code/02_estimate.R`
(step 2 of the replication package).

## Steps

Main outcomes (fixed in advance, PI approves with this card): reported leverage `rl1`, `rl2` (real deleveraging);
`rl2_gap`, `mi_share`, `jv_ta` (cosmetic channels). Sample: `sample_main == TRUE`, `dose` not missing.

1. **Pooled DiD:** `feols(y ~ dose:post | firm_id + date, cluster = ~firm_id)` for the five outcomes. Table
   `t009_did_main` (via `modelsummary`, booktabs fragment): coefficient, clustered SE in parentheses, 95 % CI, N
   (firm-half-years), number of firms, mean of `y` in the pre period. Note: sample, definition of `dose` and `post`,
   fixed effects, clustering, and the identifying assumption (parallel trends across dose levels absent the policy).
2. **Event study:** `feols(y ~ i(date, dose, ref = "2020-06-30") | firm_id + date, cluster = ~firm_id)` for the five
   outcomes. `t009_event_study.csv`: outcome, date, coefficient, SE, CI. One PDF per outcome: coefficients with 95 % CI
   over the 13 dates, horizontal line at 0, vertical dashed line between 2020-06-30 and 2020-12-31.
3. **Pre-trend test:** joint Wald test that all pre-period coefficients (dates < 2020-06-30) are zero (`fixest::wald`),
   per outcome → `t009_pretrend_tests.csv` (statistic, df, p-value). Do not test pre-periods one by one.
4. No robustness checks in this task (separate card later: broad sample, `dose_2020h1`, without `adv_missing`, without
   `fye_flag`, `rl1_alt`, balanced panel). No interpretation beyond describing signs, sizes and CIs in the report.

## Acceptance criteria

2. Every regression uses `sample_main` with non-missing `dose`, firm and date fixed effects and firm-clustered SEs
   (shown in the script and stated in the table note).
3. For one outcome of the reviewer's choice the pooled coefficient and SE in `t009_did_main.csv` are reproduced from the
   script's model object printed in the log (report the printout).
4. Event study: reference date 2020-06-30 has no coefficient (normalised to 0); 12 coefficients per outcome.
5. Pre-trend test uses only dates < 2020-06-30; one row per outcome.
6. `.tex` contains `\toprule`, `\bottomrule`, no `\documentclass`.
7. Report: per outcome the pooled coefficient with 95 % CI and the pre-trend p-value, in one table; N and number of
   firms per regression.
8. Nothing outside the write scope modified.
