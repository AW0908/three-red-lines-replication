## Steps

One observation per firm, main sample.
1. Running variable x = rl1 on 2019-12-31 − 0.70 (robustness: mean rl1 over 2017H1–2019H2 − 0.70, at least 3 dates). Treatment side: x > 0 (breach).
2. Outcomes (firm level): Δrl1 = mean rl1 over 2020H2–2022H2 minus rl1 on 2019-12-31 (main); same construction for rl2, rl2_gap, mi_share, jv_ta, log interest-bearing debt (A-shares only for levels; say so). Missing post values → firm dropped for that outcome (report N left/right).
3. **Sharp RD:** `rdrobust` local linear, triangular kernel, MSE-optimal bandwidth, robust bias-corrected CI; plus fixed bandwidths 0.05, 0.10, 0.15 and local quadratic as robustness. Report effective N left/right.
4. **Fuzzy RD:** treatment D = 1 if rl1 > 0.70 on 2020-06-30 (last balance sheet before the announcement), instrumented by x > 0 (`rdrobust(..., fuzzy = D)`); report first-stage jump and its strength.
5. **Validity:** `rddensity` density test at 0 for the 2019 running variable; placebo outcome = rl1 change 2017-12-31 → 2019-12-31 and covariates (HK listing, delisted later, log total assets, mi_share 2019) at the cutoff; placebo cutoffs x = −0.10, −0.05, +0.05, +0.10 (effects should be null).
6. Graphs: `t024_rdplot_rl1.pdf` (binned scatter of Δrl1 against x with local linear fits), `t024_density_rl1.pdf`, and graphical-only binned scatters for RL2 (threshold 1.00) and RL3 (threshold 1.00): `t024_rdplot_rl2.pdf`, `t024_rdplot_rl3.pdf` (no estimates; note the small number of firms near those cutoffs).
7. Tables: `t024_rd_main.csv/.tex` (sharp + fuzzy for all outcomes), `t024_rd_robustness.csv` (bandwidths, polynomial, alternative running variable), `t024_rd_validity.csv/.tex` (density test, placebo outcomes/covariates, placebo cutoffs). TEX notes without unescaped special characters.
