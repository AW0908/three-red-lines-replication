## Goal

For each outcome, the smallest effect of `dose × post` that the main design can detect with 80 % power at the 5 % level
(MDE), estimated **without looking at post-policy outcomes**: the standard error comes from a placebo regression on
pre-policy data only. Decides which hypotheses the proposal treats as main and which as exploratory
("Empirical Model", "Preliminary Analysis"). Script `replication/code/t008_power.R`.

## Inputs (read only)

- `replication/data/processed/panel_firm_halfyear.csv` – panel from T004

## Write scope

- `replication/code/t008_power.R`
- `replication/outputs/tables/t008_mde.csv`
- `replication/outputs/tables/t008_mde.tex`

Everything else stays unchanged.

## Steps

1. Sample: `sample_main == TRUE`, `dose` not missing, dates 2016-12-31 … 2020-06-30 only (pre-policy, 8 dates).
2. Placebo post: `placebo_post` = 1 for dates ≥ 2018-12-31.
3. For each outcome `y` in `rl1`, `rl2`, `rl2_adj`, `rl3`, `rl2_gap`, `mi_share`, `mi_gap`, `jv_ta`, `perp_te`, `inv_ta`:
   `fixest::feols(y ~ dose:placebo_post | firm_id + date, cluster = ~firm_id)`. Record N, number of firms, SE of the
   coefficient, SD of `y` (pooled, same sample) and the within-firm SD of `y` (after removing firm and date means).
4. MDE = (1.96 + 0.84) × SE (80 % power, two-sided 5 %), per one additional breached line; also as share of the pooled SD
   and of the within-firm SD; also the implied effect of moving from `dose` 0 to 3 (= 3 × MDE).
5. Heterogeneity: the same for the interaction `dose:placebo_post:soe` in
   `y ~ dose:placebo_post + dose:placebo_post:soe | firm_id + date` on firms with known `soe` – SE and MDE of the triple
   interaction for `rl1`, `rl2`, `rl2_gap`, `mi_share`.
6. Do **not** report the placebo point estimates in the output tables (only SEs and MDEs) – they are not results.
7. Table `t008_mde`: one row per outcome (and the four heterogeneity rows), columns N, firms, SE, MDE, MDE/SD, MDE/within-SD,
   3×MDE. LaTeX booktabs fragment with a note explaining the placebo approach and the 2.8 × SE rule.

## Acceptance criteria

1. `Rscript code/t008_power.R` (from `replication/`) runs twice, CSV and TEX byte-identical.
2. Only dates ≤ 2020-06-30 enter any regression (assertion in the script).
3. MDE = 2.8 × SE exactly for every row; MDE/SD and MDE/within-SD recomputable from the CSV columns.
4. No placebo coefficient appears in the outputs.
5. Report lists the MDE per outcome in plain words (e.g. "rl1: one more breached line must change rl1 by at least x
   percentage points to be detectable") and flags outcomes with MDE/within-SD > 0.5 as weakly powered.
6. Nothing outside the write scope modified.
