## Goal

PI decision (2 Nov): every table in the Online Appendix spans the full text width, in one consistent format, so the appendix reads as one document. Layout only: no number, label meaning or table content changes. Figures follow in a separate card.

## Inputs (read only)

Token budget: read only the appendix files and the table files they input; do not read replication code or logs.

- `proposal/appendix/*.tex`, the `proposal/tables/*.tex` files used in the appendix, `proposal/preamble.tex`

## Write scope

- `proposal/tables/*.tex` (appendix tables only; main-text Tables 1–6 unchanged), `proposal/appendix/*.tex` (table environments and float placement only), `proposal/preamble.tex` (shared table helpers only), `tasks/T070_report.md`

## Rules

1. **Width:** every appendix table exactly `\linewidth`: `tabularx` (or `tabular*` with `\extracolsep{\fill}`) with the extra width given to the first (label) column; numeric columns right-aligned and compact; decimal alignment with `siunitx` `S` columns where the column holds plain numbers (keep intervals and text cells as they are).
2. **Uniform style:** `booktabs` rules only (`\toprule`, `\midrule`, `\bottomrule`, no vertical lines); one font size for all appendix table bodies (`\footnotesize`) and notes (`\scriptsize` or the existing `\floatnote`); caption above, note below, same spacing everywhere; true minus signs; intervals as `$[a,b]$`.
3. **Long tables:** split or `longtable` across pages; nothing overflows the margin; no page with a single small table and large white space (`[htbp]`, `\FloatBarrier` at section ends).
4. **Two-column tables:** keep at full width; list them in the report so the PI can decide whether to merge any.
5. **Do not change** numbers, row order, labels' meaning, `\label`s or references; provide a shared helper (e.g. `\begin{apptabular}{...}`) in the preamble so new tables (T069) can use the same format.

## Acceptance criteria

1. Every appendix table at `\linewidth`; build clean; no overfull boxes > 1 pt in the appendix; main text unchanged and ending on page 15.
2. A diff check showing that no number in any table changed (extract numbers before/after and compare).
3. Report: list of all appendix tables with page, old width, new format; two-column tables listed separately.
