## Goal

A pre-specified set of robustness checks for the five main outcomes of T009, aimed first at the rl1 pre-trend
(treatment `dose` is built from the outcome levels at 2019-12-31, `state/LIMITATIONS.md` I9), then at outliers, sample
composition and imputation choices. One table spec × outcome with coefficient, CI and joint pre-trend p-value, plus
event-study figures for the two alternative treatment definitions. Feeds "Preliminary Analysis" and the referee
responses. Script `replication/code/04_robustness.R`. The list below is fixed in advance – no additional specifications.

## Steps

Outcomes: `rl1`, `rl2`, `rl2_gap`, `mi_share`, `jv_ta`. Baseline (S0) = T009: `feols(y ~ dose:post | firm_id + date,
cluster = ~firm_id)`, `sample_main`, `dose` non-missing. Every specification below changes **one** element of S0.

**Treatment definitions** (constructed in the script, firm-level, constant within firm; summary per definition in
`t011_treatment_definitions.csv`: N firms, distribution, correlation with `dose`):
- `dose2018` = `n_breached` at 2018-12-31.
- `dose_pre` = mean of `n_breached` over 2017-06-30 … 2019-12-31 (non-missing dates, at least 3; continuous 0–3).
- `distance` = `max(rl1 − 0.70, 0) / 0.10 + max(rl2 − 1.00, 0) / 0.50 + max(1.00 − rl3, 0) / 0.50`, each ratio averaged over
  2017-06-30 … 2019-12-31 before applying the formula (at least 3 dates); report its distribution.

**Specifications** (one row each × 5 outcomes):
- S1 `dose2018`; S2 `dose_pre`; S3 `distance` (treatment replaces `dose`).
- S4 S0 plus firm-specific linear trends estimated on the full period: `y ~ dose:post | firm_id[t_index] + date`
  (`t_index` = 1…13).
- S5 outcomes winsorised at the 1st/99th percentile **within each date** (all five outcomes).
- S6 balanced panel: firms with a financial row on all 13 dates.
- S7 `sample_broad` instead of `sample_main`.
- S8 `dose_2020h1` instead of `dose`.
- S9 excluding firms with any `adv_missing = TRUE` row.
- S10 excluding firms with `fye_flag = TRUE`.
- S11 `rl1_alt` instead of `rl1` (only for the rl1 row; other outcomes NA).
- S12 A-shares only; S13 HK only.

For every specification: coefficient, SE, 95 % CI, p-value, N, number of firms, and – for S0–S3 and S5–S13 – the joint
pre-trend p-value from the corresponding event study (reference 2020-06-30, pre dates < 2020-06-30; for S1 the pre dates
are < 2018-12-31 only in an additional column `pretrend_p_before_2019`, because 2019 enters the treatment definition).
S4: report the pre-trend p-value as NA (trends absorb it).

**Figures:** event studies (same layout as T009) for `rl1` and `mi_share` with `dose2018` and with `distance`.

**Table** `t011_robustness.tex`: rows = specifications, column pairs = outcomes (coefficient with SE below; pre-trend p
in a separate small row or in brackets); booktabs fragment, note describing each specification in one line.
No interpretation beyond the report table.

## Acceptance criteria

1. `Rscript code/04_robustness.R` (from `replication/`) runs twice; CSV and TEX byte-identical.
2. S0 reproduces T009 exactly (coefficient and SE to 1e-12 for all five outcomes; assertion in the script).
3. Each of S1–S13 differs from S0 in exactly the element stated (visible in the script; one function call per spec).
4. Treatment variables constant within firm; `distance` ≥ 0; `dose_pre` in [0, 3].
5. Winsorising done within date; report the number of winsorised values per outcome.
6. `.tex` contains `\toprule`, `\bottomrule`, no `\documentclass`.
7. Report: the full spec × outcome table (coefficient, CI, pre-trend p) and N/firms per spec.
8. Nothing outside the write scope modified.
