**5. Red-line ratios** (PI decisions 4, 5, 6, 9):
- `rl1` = (`tl` − `adv`) / (`ta` − `adv`); robustness `rl1_alt` = (`tl` − `adv`) / `ta`. Formula flagged `[unverified]` in the dictionary.
- `ibd` = `std` + `ltd`; robustness `ibd_ext` = `ibd` + `lease` + `notes`.
- `rl2` = (`ibd` − `cash`) / `te` (perpetuals as equity, as reported); `rl2_adj` = (`ibd` + `perp` − `cash`) / (`te` − `perp`).
- `rl3` = (`cash` − `rcash`) / `std`; where `rcash` is missing use `cash` and set `rl3_upper_bound = TRUE`.
- Breach indicators `b1` = `rl1` > 0.70, `b2` = `rl2` > 1.00, `b3` = `rl3` < 1.0; `n_breached` = `b1 + b2 + b3` (NA if any ratio NA).
- Denominator ≤ 0 → ratio NA; count these per ratio in `t004_panel_counts.csv`.

**6. Treatment intensity:** `dose` = `n_breached` on 2019-12-31; `dose_2020h1` = on 2020-06-30 (robustness); constant
within firm; `post` = `date` ≥ 2020-12-31.

**8. Outcomes:** `mi_share` = `mi` / `te`; `mi_gap` = `mi_share` − `ni_mi` / `ni` (YTD values, NA if `ni` ≤ 0);
