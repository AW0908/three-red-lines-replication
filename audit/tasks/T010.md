## Steps

1. **Copy raw data** (copy, never move) into `replication/data/raw/eastmoney/` and `replication/data/raw/wind/`;
   the two T003 tables into `replication/data/raw/audit/`. Write `MANIFEST.csv`: file, source, download/export date,
   size in bytes, SHA-256. Verify each copy's SHA-256 equals the original.
2. **Paths in `01_clean.R`:** replace every `../Daten/...` and `outputs/tables/t003_*` input path by the new
   `data/raw/...` path. No other change to the script; all outputs must stay byte-identical (step 7).
3. **`00_setup.R`:** checks the R version and that every package in `environment.lock` is installed; installs missing
   ones from CRAN (`repos` argument: `https://cloud.r-project.org`, comment with the USTC mirror for mainland China);
   prints installed vs. recorded versions and warns (does not stop) on version differences. Packages used by any script
   must all be listed – derive the list from the `library()`/`::` calls in the four scripts and add missing ones to
   `environment.lock` with the installed version.
4. **`run_all.R`** (works on Windows without a shell): sets the working directory to the folder of the script when run
   via `Rscript run_all.R`, or relies on the `.Rproj`; then runs `00_setup.R`, `01_clean.R`, `03_figures.R`,
   `t008_power.R`, `02_estimate.R` in a clean environment each (`callr` not required – use `source(..., local = new.env())`
   or `system2("Rscript", ...)`), stops at the first error, prints elapsed time per step.
   **`run_all.sh`**: same order via `Rscript`.
5. **`replication.Rproj`:** standard RStudio project file in `replication/` (opening it sets the working directory).
6. **README:** update Quick start (open `replication.Rproj` → `source("run_all.R")`, or `Rscript run_all.R`), folder
   structure, computational requirements (incl. `00_setup.R`), "Raw files" table from `MANIFEST.csv`, a note that the Wind
   workbooks are licensed (PKU Guanghua terminal) and shared with the instructor for replication only, and a changelog line.
   Expected runtime from step 7.
7. **Fresh-copy test:** copy the whole `replication/` folder to a new temporary directory **outside** the project
   (`mktemp -d`); delete `data/processed/*` and all files in `outputs/tables/` and `outputs/figures/` **in the copy only**;
   run `Rscript run_all.R` there; compare SHA-256 of every rebuilt output with the original in the project. If the
   sandbox does not allow writing outside the project, stop and report (do not test inside the project).

## Acceptance criteria

1. No script in `replication/code/` refers to a path outside `replication/` (`grep` for `\.\./` returns nothing).
2. `MANIFEST.csv` lists every raw file; all SHA-256 equal the originals in `Daten/`.
3. Fresh-copy test: `run_all.R` exits 0 and every CSV/TEX output and the panel are byte-identical to the project
   versions; PDFs identical or, if not, listed with the reason.
4. `00_setup.R` lists every package used in the four scripts; `environment.lock` contains all of them with versions.
5. `replication.Rproj` exists; README Quick start describes both ways to run and the expected runtime.
6. `Daten/` unchanged; outputs in the project unchanged (checksums before/after).
