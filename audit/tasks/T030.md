## Goal

The main panel ends in 2022H2 (13 dates). The EastMoney raw files already contain reports up to 2026 (Co-PI check: A-shares 89 codes and HK about 33–35 codes at each date 2023H1–2024H2). Build a **separate extension panel** through 2024-12-31 with exactly the same cleaning rules. It raises the number of post-policy threshold crossings for Q2 (T029), and it covers the default wave. The main panel and all existing outputs stay byte-identical.

## Inputs (read only)

- `replication/code/01_clean.R`, `replication/data/raw/` (all sources), `replication/data/processed/panel_firm_halfyear.csv`
- `state/LIMITATIONS.md`, `state/STATE.md`

## Write scope

- `replication/code/01b_extend.R` (new; it may source helper functions from 01_clean.R only if that does not re-run or rewrite the main panel; otherwise copy the needed functions verbatim and assert equality)
- `replication/data/processed/panel_firm_halfyear_ext.csv` (new), `replication/outputs/tables/t030_*`
- `replication/run_all.R`, `replication/run_all.sh` (add 01b directly after 01)
- `replication/README.md` (pipeline, outputs, changelog only)

## Steps

1. Target dates 2016-12-31 … 2024-12-31 (17 dates). Same date matching, item mapping, advance-receipt, perpetual, ownership and sample rules as 01_clean.R. Firm universe and sample_main/sample_broad as in the main panel; no new firms. dose, dose_pre and soe_final are taken from the main panel.
2. **Assert:** every row with date ≤ 2022-12-31 is identical to `panel_firm_halfyear.csv` in all columns (tolerance 1e-12 for numerics). Otherwise stop and report the differing columns.
3. Wind-only firms (delisted A/HK firms and wind_sub firms) have no data after 2022H2. Set has_row = FALSE there and do not impute. Report the counts.
4. Coverage table `t030_coverage.csv`: by date × market × source, the firms in sample_main with a balance sheet, rl1, rl2, mi, ibd. Also `t030_attrition_2023_2024.csv`: firms present in 2022H2 but missing in 2023H1–2024H2, by rounded dose_pre.
5. `t030_crossings_preview.csv`: count RL1 downward crossings (≥ 0.70 → < 0.70, consecutive dates) per half-year 2017H1–2024H2. Counts only, no estimates.
6. Variable dictionary addendum `t030_dictionary_addendum.csv` (only new or changed semantics, e.g. post2 = date ≥ 2023-06-30).

## Acceptance criteria

1. Main panel and all existing outputs byte-identical; the overlap assert passes.
2. Two runs byte-identical.
3. The report lists, per date, the number of sample_main firms with RL1 in the extension, and says plainly which firms drop out for data reasons rather than attrition (Wind-only).
4. No estimates in this card.
