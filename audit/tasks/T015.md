## Goal

The panel carries a final ownership classification for every firm (Wind where available, manual coding otherwise), and a heterogeneity table shows whether the dose_pre × post effect differs between SOEs and private developers. Needed for the "Preliminary analysis" section and as a mechanism test (soft budget constraints of SOEs).

## Steps

1. In `01_clean.R`, read `data/raw/manual/ownership_manual_coding.csv` and append three columns: `owner_class_final` (Wind-based class where `soe` is known: SOE if `soe == 1`, private if `soe == 0`; otherwise the manual `owner_class`), `soe_final` (Wind `soe` where known, else manual `soe_final`, else NA), `soe_source` ("wind" / "manual" / NA). No name matching: join on `firm_id` only. Stop if a manual firm_id is not in the universe or appears twice.
2. Report counts of `owner_class_final` and `soe_final` for `sample_main` firms (expected roughly 46 SOE / 82 private / 8 NA among 136 firms; report actual numbers).
3. New `05_heterogeneity.R` (same conventions as `02_estimate.R`: seed, one thread, firm-clustered SE, `fixef.rm = "singleton"`, sample_main, firms with non-missing `soe_final`):
   - (a) interaction: `y ~ dose_pre:post + dose_pre:post:soe_final | firm_id + date` for the five outcomes; report the private effect, the SOE − private difference and the implied SOE effect (with SE via `fixest` linear combination / `car`-free delta: use `wald`/vcov), N, firms per group;
   - (b) split sample: the main pooled spec separately for SOE and private firms.
   - Outputs: `t015_soe_heterogeneity.csv` and `.tex` (booktabs, same style as `t009_did_main.tex`, notes: which firms are coded manually, NA rule), plus `t015_ownership_counts.csv`.
   - No multiple-testing claims; just report.
4. Add `05_heterogeneity.R` to both run_all files; README updates (new variables, new script, raw file, changelog T015).
5. Fresh-copy test as in T010: all pre-existing outputs byte-identical, new outputs reproducible (two runs identical).
