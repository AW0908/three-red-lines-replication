## Goal

Four tables showing which HK firms (currently listed and delisted) and which balance-sheet items are
actually available for the firm-half-year panel 2016H2–2022H2, and which firms have non-December fiscal
year ends. They are the basis for Anton's sample and date-rule decisions (section "Context and Data").
This task excludes no firm and computes no red-line ratio. Counterpart of T001 for HK.

## Inputs (read only)

- `Daten/akshare_output/firm_list.csv` – firm list, UTF-8 with BOM; columns `code`, `name`, `board`, `market`, `fetched`
- `Daten/akshare_output/raw_hk_balance.csv` – HK balance sheets of listed firms, long format: `SECUCODE`, `SECURITY_CODE`,
  `SECURITY_NAME_ABBR`, `ORG_CODE`, `REPORT_DATE`, `DATE_TYPE_CODE`, `FISCAL_YEAR`, `STD_ITEM_CODE`, `STD_ITEM_NAME`,
  `AMOUNT`, `STD_REPORT_DATE`, `code` (55,642 rows, 36 codes)
- `Daten/akshare_output/delisted_hk_balance.csv` – same format, delisted HK firms (37,956 rows, 35 codes)
- `Daten/delistete_immobilienfirmen.csv` – list of 76 delisted developers (Wind), incl. `reused_code`, `sub`, `listed_at_policy`

## Steps

1. Read all inputs with `code` as text (5 digits, leading zeros kept).
2. Stack both balance files; add `source` = `listed` / `delisted`.
3. Define the 13 target dates: 30 June and 31 December from 2016-12-31 to 2022-12-31.
   Compute everything twice, once matching on `REPORT_DATE`, once on `STD_REPORT_DATE` (column `date_rule`).
4. Firm table: one row per code in the stacked data with `code`, `name`, `source`, `fiscal_year` (value(s) of `FISCAL_YEAR`),
   `n_dates_report` and `n_dates_std` (target dates with any non-missing `AMOUNT` for item 总资产 under each rule),
   `first_date`, `last_date` (over all dates in the file), `flag_02768` (true for code `02768`, which is a wrong firm, 国恩科技).
5. Item list: all distinct `STD_ITEM_NAME` with `STD_ITEM_CODE` and number of firms reporting them on target dates.
6. Coverage table: per item in this list and per `date_rule` × `source`: `n_present`, `n_total`, `share`, where
   `n_total` = firm-date combinations with 总资产 present. Items: 总资产, 总负债, 合同负债, 预收款项, 现金及等价物,
   受限制存款及现金, 短期贷款, 长期贷款, 应付票据, 应付票据(非流动), 永久资本证券, 少数股东权益, 股东权益,
   联营公司权益, 合营公司权益, 存货, 发展中物业, plus derived row `合同负债_OR_预收款项`.
   If an item name does not exist exactly, report the closest names from step 5 instead of guessing.
7. Fiscal-year table: firms whose `FISCAL_YEAR` ≠ `12-31` or whose `REPORT_DATE` and `STD_REPORT_DATE` differ, with
   the observed pairs.

## Acceptance criteria

1. `t003_hk_firms.csv` has exactly one row per distinct `code` in the two balance files (69; `02019` and `03333`
   appear in both files → one row each, `source` = `both`), no duplicate codes, every code a 5-character string.
2. `n_dates_report` and `n_dates_std` are between 0 and 13.
3. `flag_02768` is true for exactly one row.
4. Coverage table: `share` = `n_present` / `n_total`, within [0, 1]; `n_total` identical across items within each
   `date_rule` × `source` group.
5. No date outside the 13 target dates enters the coverage table.
6. Fiscal-year table lists every firm with a non-December fiscal year end; the 5 firms 00221, 00275, 00278, 00283, 01246
   appear if they are present in the data.
7. The run command (from `replication/`) runs without errors and recreates all four files.
8. No file under `Daten/` was modified.
