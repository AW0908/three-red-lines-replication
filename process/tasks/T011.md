## Goal

A pre-specified set of robustness checks for the five main outcomes of T009, aimed first at the rl1 pre-trend
(treatment `dose` is built from the outcome levels at 2019-12-31, `state/LIMITATIONS.md` I9), then at outliers, sample
composition and imputation choices. One table spec × outcome with coefficient, CI and joint pre-trend p-value, plus
event-study figures for the two alternative treatment definitions. Feeds "Preliminary Analysis" and the referee
responses. Script `replication/code/04_robustness.R`. The list below is fixed in advance – no additional specifications.

## Steps

Outcomes: `rl1`, `rl2`, `rl2_gap`, `mi_share`, `jv_ta`. Baseline (S0) = T009: `feols(y ~ dose:post | firm_id + date,
cluster = ~firm_id)`, `sample_main`, `dose` non-missing. Every specification below changes **one** element of S0.

**Treatment definitions** (constructed in the script, firm-level, constant within firm; summary per definition in
`t011_treatment_definitions.csv`: N firms, distribution, correlation with `dose`):
- `dose2[number withheld]` = `n_breached` at 2018-12-31.
- `dose_pre` = mean of `n_breached` over 2017-06-30 … 2019-12-31 (non-missing dates, at least [number withheld]; continuous [number withheld]–[number withheld]).
- `distance` = `max(rl1 − [number withheld], [number withheld]) / [number withheld] + max(rl2 − [number withheld], [number withheld]) / [number withheld] + max([number withheld] − rl3, [number withheld]) / [number withheld]`, each ratio averaged over
  2017-06-30 … 2019-12-31 before applying the formula (at least [number withheld] dates); report its distribution.

**Specifications** (one row each × [number withheld] outcomes):
- S1 `dose2[number withheld]`; S2 `dose_pre`; S3 `distance` (treatment replaces `dose`).
- S4 S0 plus firm-specific linear trends estimated on the full period: `y ~ dose:post | firm_id[t_index] + date`
  (`t_index` = [number withheld]…[number withheld]).
- S5 outcomes winsorised at the [number withheld]st/[number withheld]th percentile **within each date** (all five outcomes).
- S6 balanced panel: firms with a financial row on all [number withheld] dates.
- S7 `sample_broad` instead of `sample_main`.
- S8 `dose_2[number withheld]h1` instead of `dose`.
- S9 excluding firms with any `adv_missing = TRUE` row.
- S1[number withheld] excluding firms with `fye_flag = TRUE`.
- S1[number withheld] `rl1_alt` instead of `rl1` (only for the rl1 row; other outcomes NA).
- S1[number withheld] A-shares only; S1[number withheld] HK only.

For every specification: coefficient, SE, [number withheld] % CI, p-value, N, number of firms, and – for S0–S3 and S5–S1[number withheld] – the joint
pre-trend p-value from the corresponding event study (reference 2020-06-30, pre dates < 2020-06-30; for S1 the pre dates
are < 2018-12-31 only in an additional column `pretrend_p_before_2[number withheld]`, because [number withheld] enters the treatment definition).
S4: report the pre-trend p-value as NA (trends absorb it).

**Figures:** event studies (same layout as T009) for `rl1` and `mi_share` with `dose2[number withheld]` and with `distance`.

**Table** `t011_robustness.tex`: rows = specifications, column pairs = outcomes (coefficient with SE below; pre-trend p
in a separate small row or in brackets); booktabs fragment, note describing each specification in one line.
No interpretation beyond the report table.
